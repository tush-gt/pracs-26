EXPERIMENT 3 — MAPREDUCE: WORD COUNT, TOTAL WORD COUNT, MATRIX MULTIPLICATION
=============================================================================

Aim
---
Write Mapper, Reducer and Driver programs and execute them using Hadoop.

A. CHECK TOOLS
--------------
    java -version
    javac -version
    hadoop version
    hdfs dfs -ls /

If Hadoop is already configured, start it if needed:
    start-dfs.sh
    start-yarn.sh
    jps

B. CREATE WORKING FOLDER AND INPUT FILES
----------------------------------------
    mkdir -p ~/BDA_Exp3
    cd ~/BDA_Exp3

Create a small word input file:
    cat > input.txt <<'EOF'
    big data is useful
    hadoop processes big data
    map reduce processes data
    big data
    EOF

Create matrix input for A (2x5) and B (5x3). Format: MatrixName,row,column,value. Indexing is zero-based.
    cat > matrix_input.txt <<'EOF'
    A,0,0,1
    A,0,1,2
    A,0,2,3
    A,0,3,4
    A,0,4,5
    A,1,0,6
    A,1,1,7
    A,1,2,8
    A,1,3,9
    A,1,4,10
    B,0,0,1
    B,0,1,2
    B,0,2,3
    B,1,0,4
    B,1,1,5
    B,1,2,6
    B,2,0,7
    B,2,1,8
    B,2,2,9
    B,3,0,10
    B,3,1,11
    B,3,2,12
    B,4,0,13
    B,4,1,14
    B,4,2,15
    EOF

C. COMPILE JAVA PROGRAMS
------------------------

5. Create a folder for Java files:
   mkdir -p ~/bda_exp3 && cd ~/bda_exp3
6. Copy the required Java program from Exp3_Code.txt into a file with the exact name:
   WordCount.java OR TotalCount.java OR MatrixMultiply.java
   Do not paste the explanatory filename line into Java code.
Keep the .java files in this folder. Compile with the Hadoop classpath:

    javac -classpath "$(hadoop classpath)" -d . WordCount.java
    jar -cf wordcount.jar WordCount*.class

    javac -classpath "$(hadoop classpath)" -d . TotalWordCount.java
    jar -cf totalwordcount.jar TotalWordCount*.class

    javac -classpath "$(hadoop classpath)" -d . MatrixMultiplication.java
    jar -cf matrixmultiply.jar MatrixMultiplication*.class

If compilation says package org.apache.hadoop does not exist, `hadoop classpath` is not configured or Hadoop is not installed. Check `hadoop version` first.

D. RUN WORD COUNT
-----------------
    hdfs dfs -mkdir -p /user/$(whoami)/exp3/input
    hdfs dfs -put -f input.txt /user/$(whoami)/exp3/input/
    hdfs dfs -rm -r -f /user/$(whoami)/exp3/wordcount_output
    hadoop jar wordcount.jar WordCount /user/$(whoami)/exp3/input/input.txt /user/$(whoami)/exp3/wordcount_output
    hdfs dfs -cat /user/$(whoami)/exp3/wordcount_output/part-r-00000

The program lowercases tokens and removes punctuation, so repeated words with different letter case are counted together.

E. RUN TOTAL WORD COUNT
-----------------------
    hdfs dfs -rm -r -f /user/$(whoami)/exp3/total_output
    hadoop jar totalwordcount.jar TotalWordCount /user/$(whoami)/exp3/input/input.txt /user/$(whoami)/exp3/total_output
    hdfs dfs -cat /user/$(whoami)/exp3/total_output/part-r-00000

Expected total for the provided file: 15 words.

F. RUN MATRIX MULTIPLICATION
----------------------------
    hdfs dfs -mkdir -p /user/$(whoami)/exp3/matrix_input
    hdfs dfs -put -f matrix_input.txt /user/$(whoami)/exp3/matrix_input/
    hdfs dfs -rm -r -f /user/$(whoami)/exp3/matrix_output
    hadoop jar matrixmultiply.jar MatrixMultiplication /user/$(whoami)/exp3/matrix_input /user/$(whoami)/exp3/matrix_output 2 5 3
    hdfs dfs -cat /user/$(whoami)/exp3/matrix_output/part-r-00000

Arguments after paths are rows(A)=2, columns(A)=5, columns(B)=3. Matrix B must have 5 rows. This implementation outputs all cells, including zeros. Input matrices must have valid, unique coordinates and compatible dimensions.

G. IMPORTANT HADOOP OUTPUT RULE
-------------------------------
Hadoop will not write to an output directory that already exists. Remove the specific output directory before rerunning, as shown above.

COMMON ERRORS
-------------
• ClassNotFoundException: use the class name exactly as in the command and ensure the JAR contains the class.
• NoClassDefFoundError / Hadoop package missing: compile with `$(hadoop classpath)`.
• Output path exists: remove that experiment output folder.
• Input path missing: verify with `hdfs dfs -ls`.
• Matrix output wrong: check matrix dimensions, row/column indexing, and CSV record format.

VIVA
----
Mapper converts input records to intermediate key-value pairs. Reducer combines values for each key. Combiner performs local aggregation. Driver configures and submits the job. HDFS stores input/output. Matrix multiplication uses C(i,k)=sum over j of A(i,j)*B(j,k).
